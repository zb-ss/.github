# zb-ss/.github

Organization profile and shared defaults for [zb-ss](https://github.com/zb-ss).

- `profile/README.md` is the page shown on the organization's GitHub profile.
- The project list between the `REPOS` markers is generated. Don't edit it by hand: the
  [Update Profile README](.github/workflows/update-readme.yml) workflow rewrites it every
  six hours, and whenever its script or config changes.
- `.github/readme-sections.json` sets the sections. A public repository goes into the first
  section that shares one of its topics, or into the fallback section. Featured and ignored
  repositories are left out of the list.
- `FUNDING.yml` provides the Sponsor button for repositories in the organization that have
  no funding file of their own.
