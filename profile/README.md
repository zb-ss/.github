## Featured: Servonaut

[![GitHub stars](https://img.shields.io/github/stars/zb-ss/servonaut?style=flat&logo=github)](https://github.com/zb-ss/servonaut/stargazers)
[![Latest release](https://img.shields.io/github/v/release/zb-ss/servonaut)](https://github.com/zb-ss/servonaut/releases/latest)
[![PyPI](https://img.shields.io/pypi/v/servonaut)](https://pypi.org/project/servonaut/)
[![License: MIT](https://img.shields.io/badge/license-MIT-green)](https://github.com/zb-ss/servonaut/blob/master/LICENSE)

**Your servers. Your terminal. Your AI agent. One TUI.** Manage AWS, Hetzner, OVH and custom servers from one terminal, with a built-in AI assistant and an MCP server so your coding agent can work on your servers too.

<a href="https://github.com/zb-ss/servonaut"><img src="https://raw.githubusercontent.com/zb-ss/servonaut/master/docs/screenshots/demo.gif" alt="Servonaut terminal UI demo" width="720"></a>

```bash
pipx install servonaut
```
