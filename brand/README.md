# Brand assets

| File | Use |
|---|---|
| `zbss-avatar.png` | Organization avatar, 1024×1024 |
| `zbss-avatar.svg` | Avatar source. The text uses JetBrains Mono ExtraBold (800), loaded from Google Fonts. |
| `servonaut-social-preview.png` | Social preview for the servonaut repository, 1280×640 |
| `sources/servonaut-social-preview.html` | Source for the social preview |
| `sources/zbss-avatar-concepts.html` | All avatar concepts, compared at sizes from 20 px to 512 px |

Palette (from servonaut.dev): background `#070B14`, gradient `#00F2FE` → `#4FACFE`, text `#F9FAFB`, muted text `#9CA3AF`. Fonts: Inter and JetBrains Mono.

## Re-rendering

Open the HTML source in a browser at its exact size and screenshot the viewport: 1280×640 for the social preview, 1024×1024 for the avatar. Wait until the web fonts have loaded before you capture.

Keep the social preview's text at least 120 px from the left and right edges. GitHub's settings preview crops about 90 px from each side, and some sites that show link previews crop it too.
